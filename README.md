# Аналитика ЮЦ: сравнение 2025 и 2026

Это отдельная версия приложения. Исходный проект в родительской папке не изменяется.

## Запуск

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Новая вкладка

Вкладка «2025 / прогноз 2026» сравнивает фактическую общую нагрузку ЮЦ за
2025 год с линейным прогнозом на 2026 год:

```text
Прогноз 2026 = факт за январь–май × 12 / 5
```

- `СД К` не участвуют в расчётах.
- `СД Н` и `АД Н` включаются отдельными переключателями и по умолчанию выключены.
- `Консультации` и `Запросы` на вкладке сравнения по умолчанию выключены.
- Коэффициент `СД Н` и `АД Н` всегда равен 1.
- Пустые значения в показателях 2026 года считаются нулями.
- Все сотрудники файла 2026 года считаются действующими.
- Прогноз линейный и не учитывает сезонность.

## Переключение периода

В боковой панели доступен выбор `2025` или `2026 · 5 мес.`. Он переключает
источник данных на вкладках сотрудников, ЮЦ, тепловой карты и дополнительной
нагрузки. Для 2026 года показывается факт за январь–май без экстраполяции.
Экстраполяция применяется только на вкладке сравнения.

При выборе 2026 года в боковой панели появляются выключенные по умолчанию
переключатели `СД Н` и `АД Н`.

Переключатель «Экстраполировать до конца 2026 года» также выключен по
умолчанию и доступен только для 2026 года. Он умножает выбранную нагрузку на
`12/5 = 2,4` во всех обычных аналитических вкладках.
